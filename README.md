# Currículo – .NET MAUI

Aplicativo mobile desenvolvido em **.NET MAUI (.NET 10)** no Visual Studio 2026, exibindo um currículo fictício em uma página estática.

## Seções

1. Informações Pessoais (com foto de perfil ilustrativa)
2. Resumo Profissional
3. Objetivo
4. Formação Acadêmica
5. Cursos Complementares
6. Experiências & Atividades
7. Habilidades Técnicas / Ferramentas
8. Futuro Acadêmico & Carreira
9. Empresas e Objetivos

## Como executar

1. Abra `CurriculoMaui.csproj` no Visual Studio 2026 (workload .NET MAUI instalada).
2. Selecione um **Android Emulator** como destino.
3. Pressione **F5**.

Ou pela linha de comando:

```bash
dotnet build -t:Run -f net10.0-android
```

> Todos os dados deste currículo são fictícios.
